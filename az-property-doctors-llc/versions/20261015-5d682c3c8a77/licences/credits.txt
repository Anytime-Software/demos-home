CODE AND EFFECTS
React and React DOM (MIT, Meta Platforms), three.js (MIT, three.js authors), Framer Motion (MIT, Framer B.V.),
Lenis smooth scroll (MIT, darkroom.engineering), Vite (MIT).
The 3D "blueprint to built" room was written for this demo with three.js. Interaction patterns (masked text reveal,
scroll-lit words, 3D tilt cards with glare, magnetic buttons, sticky stacking cards, horizontal scroll gallery,
clip-path image reveal) follow ideas popularised by Aceternity UI and 21st.dev component libraries; they were
rewritten here with Framer Motion.
